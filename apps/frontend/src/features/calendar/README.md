# calendar

Calendar & Events shows Day, Week and Month views of saved dates. It reads only; sessions are completed on the Roadmap page.

- **Live**: active roadmap sessions and milestones and the target date (Roadmap service), and job dates from the current goal (Career service). Deadlines covers the next 14 days.
- **Not implemented, labelled Coming soon**: adding entries, Events for you and Events & development. No backend exists for these.
