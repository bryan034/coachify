# Review and scheduling service

Reviews the user’s pace and coordinates proposed adjustments to their roadmap.

## API by Jira story

**No API endpoints are implemented yet.** The `/api/v1/reviews` and `/api/v1/review-schedules` prefix is reserved.

| Jira stories | Planned purpose |
|---|---|
| A01 | Request a revision based on current progress and constraints. |
| S01–S06 | Schedule reviews, manage approval preferences and inspect automatic changes. |

See the [application API overview](../../docs/api/README.md) and [service boundaries](../../docs/architecture/service-boundaries.md).
