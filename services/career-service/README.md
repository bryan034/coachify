# Career assessment service

Compares the user’s capabilities with a target job and identifies development gaps.

## API by Jira story

**No API endpoints are implemented yet.** The `/api/v1/career` prefix is reserved.

| Jira stories | Planned purpose |
|---|---|
| J01–J05 | Read a pasted job description and review its requirements. |
| G01–G07 | Assess capabilities, explain gaps and allow corrections. |

See the [application API overview](../../docs/api/README.md) and [service boundaries](../../docs/architecture/service-boundaries.md).
