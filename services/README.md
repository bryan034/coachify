# Backend services

Profile, CV, Career, Assessment, Roadmap and Jobs have runnable FastAPI applications. Jobs fetches Singapore listings live and owns private application tracking. Assessment owns private versioned comparisons; Roadmap owns study settings, the saved adviser conversation, validated user-reviewed roadmaps, timed sessions, progress history and earlier untimed plans. Dashboard and Review remain scaffolds.

Each service README lists its available endpoints by Jira story, its specification and remaining limits. See the [API overview](../docs/api/README.md) and [service boundaries](../docs/architecture/service-boundaries.md).
