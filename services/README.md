# Backend services

Profile, CV, Career, Assessment and Roadmap have runnable FastAPI applications. Assessment owns private versioned comparisons; Roadmap owns the saved career-adviser conversation, user-reviewed plans, daily allocations and task history. Dashboard and Review remain scaffolds.

Each service README lists its available endpoints by Jira story, its specification and remaining limits. See the [API overview](../docs/api/README.md) and [service boundaries](../docs/architecture/service-boundaries.md).
